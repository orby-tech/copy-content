# Copy Content

## Что это

Браузерное расширение для Chrome и Firefox, которое одним кликом копирует основной контент текущей страницы — либо как чистый текст, либо как размеченный Markdown. Работает полностью локально: данные не уходят с устройства, сетевых запросов нет.

## Какую проблему решает

Скопировать статью со страницы «как есть» — это обычно скопировать заодно навигацию, сайдбары, баннеры, плашки cookies, рекомендованные ссылки и прочий шум. Чтобы получить нормальный текст для заметок, репостов, перевода или экспорта в редактор, приходится либо чистить вручную, либо открывать «режим чтения» и копировать оттуда.

Copy Content делает это автоматически: находит блок со статьёй (`main`, `article`, типичные `#content` / `.entry-content` и т. п.), отбрасывает мусор и кладёт в буфер только сам текст или Markdown с сохранёнными заголовками, ссылками, списками, таблицами и блоками кода.

## Кому полезно

- Пишущим людям — журналистам, блогерам, авторам рассылок: быстро забрать чужой материал в Markdown для собственных черновиков и цитирования.
- Тем, кто ведёт заметки в Markdown-редакторах (Obsidian, Notion, Bear, Logseq, Joplin): сохранять источники без ручной чистки.
- Студентам и исследователям: переносить статьи в свои конспекты без HTML-мусора.
- Разработчикам и техписателям: вытаскивать примеры кода и таблицы со страниц документации с сохранением форматирования.
- Людям, которые работают с переводом и LLM: получать «чистый» вход без навигации и хедеров.

## Что умеет

Четыре действия — две пары «целая страница» и «выбрать элемент»:

- **Copy Text** — копирует всю основную статью как обычный текст.
- **Copy Markdown** — то же самое, но с сохранением заголовков (`#`/`##`/`###`), жирного, курсива, ссылок, списков, таблиц и блоков кода.
- **Pick Text** — режим выбора: при наведении подсвечиваются элементы страницы, по клику в буфер уходит текст выбранного блока.
- **Pick Markdown** — то же, но в Markdown.

Все четыре действия доступны и в попапе кнопки расширения, и в контекстном меню (правый клик по странице, по выделению или по фрейму).

В попапе есть переключатель **«Добавлять заголовок и URL страницы»**. Когда он включён, перед скопированным контентом добавляется источник: в Markdown — как `[Заголовок](URL)`, в обычном тексте — двумя строками (заголовок + ссылка). Настройка сохраняется через `chrome.storage.sync`, поэтому переключатель не нужно ставить заново на каждой странице и он синхронизируется между устройствами. Действует и на кнопки в попапе, и на пункты контекстного меню. Удобно для сбора ссылок в Notion/Obsidian, цитирования источников и LLM-промптов, в которые нужно подложить источник.

После копирования всплывает короткий тост со счётчиком символов («Markdown copied · 5.4k chars»), чтобы было видно, что копирование прошло.

Расширение умеет работать со страницами, где основной контент лежит внутри `iframe` (читалки, встраиваемые статьи): запускает извлечение во всех фреймах и берёт самый длинный непустой результат.

## Поддерживаемые языки интерфейса

Английский, испанский, хинди, русский. Локаль выбирается автоматически по языку браузера.

## Конфиденциальность

- Никаких сетевых запросов из расширения.
- Никакой телеметрии, аналитики, удалённой загрузки скриптов.
- Из разрешений — `activeTab`, `scripting`, `clipboardWrite`, `contextMenus`, `storage`. Они нужны соответственно для доступа к активной вкладке по клику пользователя, для запуска скрипта-экстрактора в странице, для записи в буфер, для пунктов в правом клике и для сохранения настроек пользователя.
- Содержимое страниц никогда не покидает браузер.

## Где доступно

- Chrome Web Store — для Chrome, Edge, Brave, Opera и других Chromium-браузеров.
- addons.mozilla.org — для Firefox (поддерживается Firefox 142+).
- Локально — режим «Load unpacked» / «Load Temporary Add-on» из исходников репозитория.
