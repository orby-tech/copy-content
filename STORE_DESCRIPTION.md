# Short description (≤132 chars)

Copy main page content as text or Markdown. Pick any element to grab just that part. Runs locally — nothing leaves your browser.

# Full description

Extracts the main content of a page (main, article, content) and skips navigation, sidebars, and banners.

Four actions: Copy Text and Copy Markdown copy the whole article; Pick Text and Pick Markdown let you hover over any element and copy just that part. All four are also available from the right-click context menu.

Markdown output preserves headings, bold, italic, links, lists, tables, and code blocks.

Works in Chrome and Firefox. UI is localized into English, Spanish, Hindi, and Russian.

No data is sent anywhere — everything runs locally on click.
